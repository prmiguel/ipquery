# Prompts — SKILL.md Generation, Optimization & Comparison

Reusable prompt templates for creating, optimizing, and comparing `SKILL.md` files for any API/service. Swap bracketed parts for your target API.

## Available Prompts

| # | File | Purpose |
|---|---|---|
| 1 | `generate-skill.md` | First-pass SKILL.md generation from API docs — complete, not optimized |
| 2 | `optimize-skill.md` | Reduce existing SKILL.md token count without losing functionality |
| 3 | `compare-skills.md` | Compare two SKILL.md versions side-by-side on size, coverage, and risk |

## Usage

Copy the contents of the relevant `.md` file and paste it as a prompt into any AI coding agent (OpenCode, Claude Code, Cursor, etc.).
